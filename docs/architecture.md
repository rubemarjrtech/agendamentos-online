## Arquitetura

- O projeto usa NestJS para tirar proveito da sua natureza modular
- Projeto deve seguir o padrão Monolito Modular:
  Siga as melhores práticas recomendadas pelo padrão (caso não saiba, peça exemplos ao usuário) e evite anti-patterns comuns (caso não saiba, peça exemplos ao usuário)
- O projeto usa uma arquitetura de cache para locks distribuídos com Redis e Banco de Dados Relacional com Postgresql
